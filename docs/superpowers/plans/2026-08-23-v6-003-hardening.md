# V6-003 API, web và supply-chain hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with TDD and verification checkpoints.

**Goal:** Bổ sung rate limiting bounded, CORS/header policy, BFF request budget, runtime secret safety và repeatable dependency/container/secret scan evidence cho deployment protected.

**Architecture:** Giữ modular monolith và process-local in-memory fixed-window limiter; key theo route + client/session fingerprint để không thêm Redis trước V6-006 benchmark. FastAPI vẫn là policy point, Next.js BFF chỉ forward same-origin session/CSRF với timeout/size/rate budget. Public deployment class fail-closed khi còn local defaults; secret manager cụ thể vẫn là deployment concern của V6-004.

**Tech Stack:** Python stdlib, FastAPI/Starlette middleware, PostgreSQL unchanged, Next.js headers, npm lockfile, Docker Scout và PowerShell scan scripts.
