# Kế hoạch V6-004 — CI/CD, deploy và rollback

## Mục tiêu

Tạo command surface có thể chạy giống nhau ở local và CI cho quality gate, migration, deployment smoke
và application rollback. Không đưa provider, secret hoặc public host cụ thể vào repository.

## Phạm vi

1. GitHub Actions chạy Python default/integration tests, static gates, web check, Compose migration/API
   smoke và Trivy critical/high gate cho API/crawler image.
2. Compose nhận image qua DEVRADAR_APP_IMAGE để deploy/rollback không sửa source.
3. scripts/smoke.ps1 kiểm tra health contract bounded retry.
4. scripts/migrate.ps1 chỉ cho alembic check và upgrade head; không tự downgrade.
5. scripts/deploy.ps1 fail-closed cho protected/public configuration và chạy database → migration →
   API → smoke theo thứ tự.
6. scripts/rollback.ps1 triển khai một image đã tồn tại và chạy lại smoke.
7. ADR, Operations, Roadmap và evidence ghi rõ forward-compatible migration, HTTPS ingress boundary,
   required secrets và chưa claim public deployment.

## Không thuộc phạm vi

- Không tự tạo hoặc lưu production secret, Docker Hub credential, TLS private key hoặc host credential.
- Không thêm reverse proxy, Redis, worker, Kubernetes, Terraform hoặc cloud SDK.
- Không tự động downgrade database sau deploy.
- Không mark V6-003 pass khi full Trivy report và fixable-finding gate chưa có kết quả cuối.

## Kiểm chứng

- YAML parse và link scan.
- PowerShell parser/help cho mọi script.
- Local Compose deploy trên database mới: migration head, API health.
- Local application-image rollback về image tag đã có: API health.
- Python/web/static gates và final diff.
